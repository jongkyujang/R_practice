# R 기초 실습 — RNA 발현 데이터 시각화

설치 없이 브라우저만으로 모두가 같은 R 환경에서 실습합니다.

## 0. 시작하기 (5분)

1. GitHub에 로그인합니다. (계정이 없으면 github.com에서 가입)
2. 아래 링크를 눌러 Codespace를 만듭니다.
   https://codespaces.new/YOUR_GITHUB_ID/R_practice?quickstart=1
3. 1~2분 기다리면 VS Code 화면이 열립니다.
4. `Ctrl+Shift+P` → **R: Create R Terminal** 을 선택합니다.
5. 오른쪽 아래에 R 터미널이 열리면 준비 완료입니다.

> **팁**: Codespace 화면이 뜨고 아래쪽에 "R 환경 설치 중..." 메시지가 보이면,  
> 설치가 끝날 때까지 기다렸다가 R 터미널을 엽니다.

## 1. 실습 순서

| 순서 | 파일 | 내용 |
|------|------|------|
| 1 | `scripts/01_basics.R` | R 기본 문법 — 주석, 변수, 벡터, 데이터 프레임, 파이프 |
| 2 | `scripts/02_heatmap.R` | RNA 발현 데이터 로드 → 계층적 군집화 → Heatmap |

## 2. 코드 실행 방법

1. 왼쪽 파일 탐색기에서 `scripts/01_basics.R`을 클릭해 엽니다.
2. 실행하고 싶은 줄에 커서를 놓습니다.
3. **Shift + Enter** 를 누르면 해당 줄이 아래 R 터미널에서 실행됩니다.
4. 여러 줄을 드래그로 선택한 뒤 Shift + Enter 하면 한꺼번에 실행됩니다.

## 3. 그래프 보기

- 그래프를 그리는 코드를 실행하면 오른쪽에 **Plots** 창이 자동으로 열립니다.
- 창이 보이지 않으면 `Ctrl+Shift+P` → **R: Show Plot Viewer** 를 선택하세요.

## 4. 실습 데이터

| 파일 | 내용 |
|------|------|
| `data/expression.csv` | 유전자 40개 × 샘플 12개 (Tumor 6 + Normal 6) |

> **주의**: `data/expression.csv`는 **교육용 가상 데이터**입니다.  
> 실제 환자 데이터나 연구 결과가 아닙니다.

## 5. 막혔을 때

1. 에러 메시지를 소리 내어 읽기
2. R 터미널에서 `getwd()` 로 현재 위치 확인
3. `?함수명` 으로 도움말 확인 (예: `?heatmap`)
4. 조교/교수에게 질문
